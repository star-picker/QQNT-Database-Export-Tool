查询命令 (List)

                
用于获取好友、群聊、数据库结构等基本信息。

                
    
                    
  • 列出好友: /api?command=list_friends
    • 
                    
  • 列出群聊: /api?command=list_groups
    • 
                    
  • 列出数据库结构: /api?command=list_schema
    • 
                    
  • 列出所有可导出字段: /api?command=list_fields
    • 
                

            


            
            

                
获取聊天记录

                
获取指定会话的聊天记录。

                
示例: /api?command=get_chat_history&type=friend&id=u_...&limit=50

                

                    
参数说明示例值

                    
                        
command固定为 get_chat_history

                        
type会话类型 (friend 或 group)friend

                        
id好友或群聊的UIDu_abcde... 或 g_abcdef...

                        
limit(可选) 返回的最大消息数量，默认20050

                        
before_ts(可选) 获取此时间戳之前的消息 (用于翻页)1672502400

                        
from_ts(可选) 获取此时间戳之后的消息1672416000

                    
                

            


            
            

                
导出命令 (Export)

                
触发服务器执行导出任务。这是一个同步操作，请求会等待任务完成后返回结果日志。所有参数均为可选，但必须提供 `friends` 或 `groups` 之一。

                
示例: /api?command=export&mode=individual&friends=12345,67890&format=md&start=2023-01-01

                

                     
参数说明示例值

                     
                        
command固定为 export

                        
mode导出模式 (individual 或 timeline), 默认 individualtimeline

                        
friends好友QQ号或UID, 多个用逗号分隔, 或 all12345,u_abc...

                        
groups群号或群UID, 多个用逗号分隔, 或 all54321,g_abc...

                        
format导出格式 (md, txt, html, json-custom, csv-custom), 默认 mdhtml

                        
start / end时间范围 (格式: YYYY-MM-DD 或 "YYYY-MM-DD HH:MM:SS")2023-01-01

                        
custom_fields自定义格式所需的字段代码, 逗号分隔40050,40020,40800

                        
group_dirs是否为好友按分组创建目录 (true / false), 默认 falsetrue

                        
location指定一个自定义的根导出目录路径C:/Exports

                    
                

            

            
            
            

                 
其他导出命令

                 
用于导出群成员等附加数据，或原始表数据。

                 
导出群成员示例: /api?command=export_extra&group=12345&type=members

                 
原始数据导出示例: /api?command=export_raw&db=nt_msg.decrypt.db&table=c2c_msg_table&columns=40050,40020
